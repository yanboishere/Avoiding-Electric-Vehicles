# 전기바이크를 피해라! Avoiding Electric Vehicles

> 광저우와 선전에는 자전거도로가 없는 길이 많습니다. 걸어서, 자전거로, 혹은 차를 몰고 나서면 전기바이크가 사방에서 튀어나옵니다. 역주행, 추월, 틈새 끼어들기, 무작정 돌진, 급정거…… 1분 동안 살아남으세요.

Godot 4(GL Compatibility) · Windows / macOS · 1280×720 · 12스테이지 · 걷기 / 자전거 / 운전 + 무적 모드

![메인 메뉴](docs/screenshots/menu.jpg)

## 플레이 방법

| 조작 | 걷기 / 자전거 | 운전 |
|---|---|---|
| 이동 | WASD / 방향키 / 게임패드 스틱 | W 가속 · S 브레이크 · A / D 차로 변경 |
| 신호 위반 | 연석 앞에서 ↑를 0.5초 누르기, 또는 스페이스 / 게임패드 A | 빨간불일 때 그냥 정지선을 넘기 |
| 일시정지 / 나가기 | ESC로 일시정지, 일시정지 중 Q로 메뉴 | 왼쪽과 같음 |
| 전체화면 | F11 또는 Alt+Enter | 왼쪽과 같음 |

**목표**
- 걷기 / 자전거: 스테이지마다 60초. 인도를 따라 계속 앞으로 나아가며, 3번 치이면 실패합니다.
- 운전: 60초 안에 목적지에 도착해야 하고, 시간을 넘기면 지각입니다. 차·전기바이크·보행자와 부딪히면 모두 목숨이 깎입니다.

**만나게 될 것들**
- **전기바이크**: 정면 역주행, 뒤에서 추월(화면 아래 빨간 삼각형 + "빵빵" 경고), 지그재그 주행, 가게 앞 / 길가에서 돌발, 차량 사이 틈새 끼어들기, 배달하느라 갑자기 급정거(멈추면 장애물이 됨), 짐 운반, 우비 착용……
- **보행자**: 같은 방향으로 느릿느릿 걷는 사람, 마주 오는 사람, 폰만 보다가 비틀거리는 사람, 나란히 걷는 사람, 가만히 서 있는 사람. 운전할 때는 횡단보도를 건너거나 무단횡단하는 사람도 있습니다.
- **장애물**: 지하철 입구, 공유자전거, 길가에 세워 둔 전기바이크, 돌기둥, 노점. 운전할 때는 불법주차 차량, 공사 펜스, 정류장에 들어오는 버스가 있습니다. 장애물은 통과할 수 없으며, 화면 아래쪽 끝까지 밀리면 걸려 넘어져 체력이 깎입니다.
- **신호등**: 걷기 중 빨간불이면 화면이 멈춥니다. 신호를 기다리는 동안에도 전기바이크가 신호를 무시하거나 내 옆으로 비집고 들어옵니다. 운전할 때는 직접 브레이크를 밟아 멈춰야 합니다. **신호를 위반하면 현재 점수의 25%가 깎이고, 교차로 안에서 옆길 차량에 치이면 바로 GAME OVER입니다.**
- **날씨**: 폭우 때는 노면이 미끄럽고 제동 거리가 길어집니다. 야간에는 화면이 어두워져 헤드라이트와 가로등에만 의지해야 합니다.

**점수와 등급**
- 오래 버틸수록 / 멀리 갈수록 점수가 높아집니다. 아슬아슬 회피 +50, 클리어 시 남은 목숨 하나당 +300(운전은 남은 시간 점수 추가).
- 운전 중 버스전용차로를 달리면 초당 -15(공사 구간이나 불법주차 차량을 피하기 위한 우회는 감점 없음).
- 등급: S 노미스 클리어 · A 1번 치임 · B 클리어 · C 실패.
- **이전 스테이지를 클리어해야 다음 스테이지가 열리며**, 기록은 자동 저장됩니다.

## 게임 모드

### 🚶 걷기
가장 자유롭고, 언제든 멈췄다 갈 수 있습니다. 치러우(아케이드 건물) 옛 거리, 유리 빌딩 상가거리, 도시 속 마을의 인도에서 전기바이크와 보행자를 피하고, 교차로에서는 빨간불을 기다려야 합니다.

![걷기 중 신호 대기](docs/screenshots/red_light.jpg)

### 🚲 자전거
더 빠르지만 관성이 있고 충돌 범위가 넓으며, 폭우 때는 더 잘 미끄러집니다.

![자전거 모드](docs/screenshots/bike_mode.jpg)

### 🚗 운전
스테이지마다 근처의 **실제로 차가 다닐 수 있는 도로 구간**으로 바뀝니다(보행자 거리나 도시 속 마을 안쪽 골목처럼 차가 못 들어가는 곳은 인접 도로로 대체). 차로 수, 중앙 분리, 측도 / 자전거도로, 버스전용차로, 제한속도, 교차로 이름은 모두 공개 자료를 바탕으로 설계했습니다. 왼쪽 아래에는 속도, 제한속도 표지판, 남은 거리가, 오른쪽 위에는 앞 교차로의 신호등이 표시됩니다.

![운전 모드](docs/screenshots/drive_6.jpg)

### 💥 무적 모드
메인 화면에서 한 번에 켤 수 있습니다. 체력이 닳지 않고 빨간불도 무시하며, 부딪힌 전기바이크는 전부 **날려 버립니다**(한 대당 +100, 연속 보너스 있음). 12스테이지가 모두 열립니다. 보행자와 차량은 여전히 통과할 수 없어서 겹쳐 지나가지 않습니다. 무적 모드의 기록은 저장되지 않습니다.

## 스테이지 소개

광저우와 선전이 번갈아 나오며 점점 어려워집니다. 각 스테이지의 설정은 `scripts/levels.gd`에 있습니다(운전 구간은 그 안의 `DRIVE`, 주석에 도로 정보 출처를 적었고 정확한 데이터를 찾지 못한 것은 "估(추정)"로 표시).

### 스테이지 1 · 광저우 · 톈허·티위시루
*Guangzhou · Tiyu West Road*

- **걷기 / 자전거**: 입문 스테이지: 티위시루 지하철역 앞. 정면으로 역주행해 오는 전기바이크가 제일 많다. (치러우 옛 거리 · 교차로 2곳(톈허난이루, 톈허루))

## 실행

[Godot 4.7](https://godotengine.org/download)이 필요합니다.

```
Godot --path .                                         # 바로 플레이
Godot -e --path .                                      # 에디터 열기
Godot --path . -- --autostart=drive --level=7 --god    # 메뉴를 건너뛰고 바로 스테이지 시작(walk/bike/drive, level 0–11), 체력 감소 없음
Godot --path . -- --unlock-all | --reset-save | --rules | --support | --invincible
```

## 테스트
```
Godot --headless --path . --script tests/car_overlap_test.gd   # 걷기/자전거: 차끼리 안 겹침, 차가 전기바이크를 안 덮침, 교차로가 모두 나타남
Godot --headless --path . --script tests/drive_test.gd         # 운전: 자율주행으로 12스테이지 주행, 어떤 참가자도 서로 겹치지 않음
Godot --headless --path . --script tests/jaywalk_test.gd       # 신호 위반 시 25% 감점, 다시 전진, 차에 치이면 GAME OVER
Godot --headless --path . --script tests/jaywalk_keys_test.gd  # 실제 키 입력: W / 스페이스를 누르고 있으면 모두 신호 위반 가능
Godot --headless --path . --script tests/font_test.gd          # 모든 중국어 문자 표시 가능(Smiley Sans에 없어 시스템 글꼴로 대체되는 글자 목록 출력)
Godot --headless --path . --script tests/invincible_test.gd    # 무적 모드로 마구 돌진: 플레이어가 어떤 물체와도 겹치지 않음
Godot --headless --path . --script tests/light_test.gd         # 신호등이 빨간불에서 멈춰 버리지 않음
Godot --headless --path . --script tests/audit_test.gd         # 운전 스테이지 점검: 도착률 / 정체 / 최장 빨간불 / 우회 / 겹침
```

스크린샷은 `tools/screenshot.gd`로 생성합니다(녹화 중에는 창이 가려지지 않게 하거나 `--always-on-top`을 추가하세요).
```
Godot --always-on-top --path . --script tools/screenshot.gd --write-movie /tmp/shot/f.png --fixed-fps 10 --quit-after 200 -- --only=0 --mode=drive
```

## 기타
- 그래픽과 효과음은 모두 프로시저럴로 생성하며, 외부 아트 소스는 사용하지 않습니다.
- 글꼴: [得意黑 Smiley Sans](https://github.com/atelier-anchor/smiley-sans)(SIL OFL 1.1, 라이선스는 `fonts/SmileySans-OFL.txt` 참조). 없는 글자는 시스템 중국어 글꼴로 대체됩니다.
- 저장 위치: `user://save.cfg`(해제 진행도, 스테이지별 최고 기록, 이동 수단, 규칙 확인 여부, 무적 모드 on/off).
- 메인 화면에 "개발자 후원" 페이지가 있으며(주소를 클릭하면 복사됨), `scripts/main.gd`에서 `SUPPORT_ENABLED`를 `false`로 바꾸면 숨길 수 있습니다.
