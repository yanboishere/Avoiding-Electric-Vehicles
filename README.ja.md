# 電チャリをよけろ！ Avoiding Electric Vehicles

> 広州や深圳では、自転車レーンのない道路がたくさんあります。歩いて、自転車で、あるいはクルマで出かけると、電動バイク（電チャリ）が四方八方から現れます：逆走、追い越し、すり抜け、飛び出し、急ブレーキ……。この 1 分間を生き延びろ。

Godot 4（GL Compatibility）· Windows / macOS · 1280×720 · 全 12 ステージ · 徒歩 / 自転車 / クルマ + 無敵モード

![メインメニュー](docs/screenshots/menu.jpg)

## 遊び方

| 操作 | 徒歩 / 自転車 | クルマ |
|---|---|---|
| 移動 | WASD / 矢印キー / コントローラーのスティック | W 加速 · S ブレーキ · A / D 車線変更 |
| 信号無視 | 縁石の前で ↑ を半秒長押し、または スペース / コントローラーの A | 赤信号のまま停止線を突っ切る |
| 一時停止 / 終了 | ESC で一時停止、一時停止中に Q でメニューへ | 左と同じ |
| 全画面 | F11 または Alt+Enter | 左と同じ |

**目標**
- 徒歩 / 自転車：各ステージ 60 秒。歩道をひたすら前へ進み、3 回ぶつかると失敗。
- クルマ：60 秒以内に目的地へ。時間切れは遅刻扱い。車・電チャリ・歩行者にぶつかるとライフが減る。

**出てくるもの**
- **電チャリ**：正面から逆走、背後から追い越し（画面下に赤い三角 +「ピピッ」で予告）、蛇行運転、店先や路肩から飛び出し、車の流れの中をすり抜け、出前のために急停車（止まると障害物に）、荷物運び、雨ガッパ姿……
- **歩行者**：同じ方向にのろのろ歩く人、正面から来る人、スマホを見ながらふらふら歩く人、横に並んで歩く人、立ち止まったままの人。クルマでは横断歩道を渡る人や道路を横切る人も。
- **障害物**：地下鉄の出入口、シェアサイクル、路肩に停めた電チャリ、車止め、屋台。クルマでは違法駐車、工事フェンス、停留所に入るバス。障害物は通り抜けできず、画面の下端に押し込まれるとつまずいてライフが減る。
- **信号**：徒歩では赤信号で画面が止まるが、信号待ちの間も電チャリが信号無視したり、すぐそばに詰め寄ってきたりする。クルマは自分でブレーキをかけて止まること。**信号無視すると現在のスコアの 25% を没収、交差点内で横から来た車にはねられたら即 GAME OVER。**
- **天気**：豪雨の日は路面が滑りやすく制動距離が伸びる。夜間は画面が暗くなり、ライトと街灯だけが頼り。

**スコアとランク**
- 長く粘るほど / 遠くまで走るほど高得点。ニアミス +50。クリア時に残りライフ 1 つにつき +300（クルマは残り時間ボーナスも加算）。
- クルマでバス専用レーンを走ると毎秒 -15（工事や違法駐車を避けるための通行は減点なし）。
- ランク：S ノーミスでクリア · A 被弾 1 回 · B クリア · C 失敗。
- **前のステージをクリアすると次のステージが解放**され、記録は自動でセーブされます。

## ゲームモード

### 🚶 徒歩
いちばん小回りが利き、いつでも止まれる。騎楼（アーケード建築）の街並み、ガラス張りの商業街、城中村の歩道で電チャリや歩行者をかわし、交差点では赤信号を待つ。

![徒歩で信号待ち](docs/screenshots/red_light.jpg)

### 🚲 自転車
スピードは速いが慣性があり当たり判定も大きい。豪雨の日はさらに止まりにくい。

![自転車モード](docs/screenshots/bike_mode.jpg)

### 🚗 クルマ
各ステージが近くの**実際に車で走れる道路**に切り替わる（歩行者天国や城中村の路地など車で入れない場所は、隣の道路を走る）。車線数、中央分離帯、側道 / 自転車道、バス専用レーン、制限速度、交差点名はすべて公開資料をもとに設計。左下は速度・制限速度標識・残り距離、右上は前方の交差点の信号。

![クルマモード](docs/screenshots/drive_6.jpg)

### 💥 無敵モード
メニューからワンタッチでオン：ダメージなし、信号無視OK、ぶつかった電チャリは全部**ぶっ飛ぶ**（1 台 +100、コンボあり）。全 12 ステージが解放される。歩行者や車は通り抜けできないので、めり込むことはない。無敵モードの記録はセーブされません。

## ステージ紹介

広州と深圳が交互に登場し、だんだん難しくなる。各ステージの設定は `scripts/levels.gd` にある（クルマの道路データはその中の `DRIVE`。コメントに道路状況の出典を記載し、正確なデータが見つからないものは「推定」と表記）。

### ステージ 1 · 広州 · 天河・体育西路
*Guangzhou · Tiyu West Road*

- **徒歩 / 自転車**：入門ステージ：地下鉄体育西路駅の前。正面から逆走してくる電チャリが一番多い。（騎楼の古い街並み · 交差点 2 か所（天河南一路、天河路））
- **クルマ · 体育西路**：片側3車線の6車線道路で交通量はものすごい。天河城の前ではタクシーが客を乗降させ、配達の電チャリが端を逆走してくる。
  - 往復 6 車線 · 中央ガードレール · 制限速度 50 km/h · 目的地まで 380 m · 青 8 秒 / 赤 6 秒 · 交差点：天河南一路、天河路
  - 道路状況の出典：体育西路は南北方向、幅 44 m、往復 6 車線、交通量は非常に多い（Wikipedia）

### ステージ 2 · 深圳 · 福田・華強北
*Shenzhen · Huaqiang North*

- **徒歩 / 自転車**：電子市場の前。荷物運びの電チャリが段ボールを人の背丈より高く積んでいる。（ガラス張りの商業街 · 交差点 2 か所（振華路、紅茘路））
- **クルマ · 振華路（一方通行）**：華強北路は歩行者天国で車は入れないので振華路へ。西から東への一方通行で右側に電動車レーンがあるのに、電チャリはわざわざ車道を走ってくる。
  - 一方通行 3 車線 · 右側にガードレールで仕切られた自転車道 · 制限速度 40 km/h · 目的地まで 320 m · 青 7 秒 / 赤 5 秒 · 交差点：燕南路、華発北路
  - 道路状況の出典：華強北路の紅茘路〜深南大道区間は 2017 年から歩行者天国で、自動車は進入不可。振華路は西から東への一方通行で、2021 年に車道と自転車道の共用化を試験導入し、右側をガードレールで仕切って電動車レーンにした（深圳交通警察の通告 / 南方+）

### ステージ 4 · 深圳 · 南山・科技園
*Shenzhen · Science Park*

  - 道路状況の出典：科苑路は朝夕のラッシュ時に大渋滞し、南行きは 3 車線から 4 車線に拡幅（深圳交通警察 / 知乎）。北行きは 3 車線（推定）。深圳交通警察は AI で信号サイクルを最適化しグリーンウェーブ区間を整備（深圳交通警察）。ここでは 3 つの交差点をグリーンウェーブで連動させている

## 実行方法

[Godot 4.7](https://godotengine.org/download) が必要です。

```
Godot --path .                                         # そのまま遊ぶ
Godot -e --path .                                      # エディターを開く
Godot --path . -- --autostart=drive --level=7 --god    # メニューを飛ばして直接ステージへ（walk/bike/drive、level 0–11）、ダメージなし
Godot --path . -- --unlock-all | --reset-save | --rules | --support | --invincible
```

## テスト
```
Godot --headless --path . --script tests/car_overlap_test.gd   # 徒歩/自転車：車同士が重ならない、車が電チャリを踏まない、交差点がすべて出現する
Godot --headless --path . --script tests/drive_test.gd         # クルマ：自動運転で 12 ステージを走行、どの参加者も互いに重ならない
Godot --headless --path . --script tests/jaywalk_test.gd       # 信号無視で 25% 減点、前進再開、車にはねられて GAME OVER
Godot --headless --path . --script tests/jaywalk_keys_test.gd  # 実際のキー入力：W 長押し / スペース のどちらでも信号無視できる
Godot --headless --path . --script tests/font_test.gd          # すべての中国語文字が表示できる（得意黒に無くシステムフォントにフォールバックする字を列挙）
Godot --headless --path . --script tests/invincible_test.gd    # 無敵モードで暴走：プレイヤーが何ともめり込まない
Godot --headless --path . --script tests/light_test.gd         # 信号が赤のまま固まらない
Godot --headless --path . --script tests/audit_test.gd         # クルマステージの健康診断：到着率 / 渋滞 / 最長の赤信号 / 迂回通行 / 重なり
```

スクリーンショットは `tools/screenshot.gd` で生成します（録画中はウィンドウが隠れないようにするか、`--always-on-top` を付けてください）：
```
Godot --always-on-top --path . --script tools/screenshot.gd --write-movie /tmp/shot/f.png --fixed-fps 10 --quit-after 200 -- --only=0 --mode=drive
```

## その他
- グラフィックと効果音はすべてプログラムで生成しており、外部のアート素材は使っていません。
- フォント：[得意黒 Smiley Sans](https://github.com/atelier-anchor/smiley-sans)（SIL OFL 1.1、ライセンスは `fonts/SmileySans-OFL.txt` を参照）。収録されていない文字はシステムの中国語フォントにフォールバックします。
- セーブデータの場所：`user://save.cfg`（解放状況、各ステージのベスト記録、移動手段、ルール画面を見たかどうか、無敵モードのオン/オフ）。
- メニューに「作者を応援」画面があります（アドレスをクリックでコピー）。`scripts/main.gd` の `SUPPORT_ENABLED` を `false` にすると非表示にできます。
